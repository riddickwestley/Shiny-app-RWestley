# 2024 Fatal Vehicle Accident Data

## Project Description
This project is an interactive R Shiny application that explores 2024 fatal motor vehicle accident data. Users can analyze fatal crashes based on weather, harmful events, rural and urban locations, time of day, and day of the week.

The application also includes a VMT Analysis tab that compares state fatal crash rates using vehicle miles traveled.

## Deployed Application
https://rwestley22.shinyapps.io/Riddick_Car_2024/ 

## Source Code
The source code and required datasets for this application are available in this GitHub repository.

## How to Run
Download the repository, open 'Riddicks_Shiny_Updated.R' in RStudio, and click Run App. Required packages include `shiny`, `bslib`, `dplyr`, and `ggplot2`.

## Data Files
- `accident.csv`: Fatal vehicle accident data.
- `VMT_2024.csv`: Vehicle miles traveled data.
